# Simple Chatbot

A simple **rule-based chatbot built with Python** that responds to greetings, basic questions, and goodbye commands using keyword matching.

## Features

* Responds to common greetings such as `hello`, `hi`, and `hey`
* Answers basic questions like `how are you` and `what is your name`
* Handles goodbye messages
* Supports `quit` and `exit` commands
* Continuously accepts user input until the chat is ended
* Provides a default response for unknown inputs

## Technologies Used

* **Python 3**
* Conditional statements
* Loops
* String manipulation
* User input handling

## How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd simple-chatbot
```

3. Run the chatbot:

```bash
python chatbot.py
```

## Example

```text
Simple Chatbot
Type 'quit' or 'exit' to end the chat.

You: hello
Bot: Hello! How can I help you?

You: how are you?
Bot: I'm doing great! Thanks for asking.

You: what is your name?
Bot: I'm a simple rule-based chatbot.

You: quit
Bot: Goodbye! Chat ended.
```
